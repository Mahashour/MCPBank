## Spring Boot Bank System with MCP

This is a Bank backend made with Spring Boot with MCP server and a chatbot client applied on it.

The AI chat bot can use the tools it is given to answer requests in plain English and find the correct tool for it.

Setup instructions:
- Have Ollama running in the background with the correct model downloaded (llama3.2:3p)
- Package
- Run
- Go to localhost:8080/chat.html to talk with the AI.
